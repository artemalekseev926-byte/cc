# Как выпустить DeskForge в Steam — пошаговый гайд

Гайд рассчитан на то, что вы делаете это впервые. Шаги идут в том порядке, в котором их нужно выполнять.

**Сроки.** От регистрации до кнопки «Выпустить» уходит минимум **~30 дней**. Это требование Valve: после оплаты взноса нельзя выпустить приложение раньше чем через 30 дней, а страница «Скоро выйдет» должна провисеть хотя бы 2 недели. Поэтому регистрироваться стоит как можно раньше, параллельно с доработкой.

---

## 0. Что понадобится

- Компьютер с **Windows 10/11** — для проверки приложения и загрузки сборки.
- **100 $** на взнос Steam Direct (за каждое приложение). Valve возвращает его, когда приложение заработает 1000 $.
- Паспорт для проверки личности, банковский счёт для выплат и налоговая анкета.
- Steam-аккаунт с включённым Steam Guard (мобильный аутентификатор).

> ⚠️ **Если вы из России.** С 2022 года оплата российскими картами в Steam недоступна, а выплаты на российские банки затруднены. Скорее всего, понадобится зарубежная карта или счёт (или издатель, который выпустит приложение от своего имени). Проверьте этот вопрос **до** начала регистрации.

---

## 1. Регистрация в Steamworks

1. Откройте https://partner.steamgames.com и войдите своим Steam-аккаунтом.
2. Нажмите **Join Steamworks** / «Присоединиться», примите соглашение о распространении (Steam Distribution Agreement).
3. Заполните **Paperwork** (документы):
   - имя или название компании, адрес;
   - **банковские данные** для выплат;
   - **налоговую анкету**: для не-резидентов США это форма W-8BEN (физлицо) или W-8BEN-E (компания), заполняется прямо на сайте;
   - **проверку личности** (Identity Verification).
4. Оплатите **Steam Direct Fee — 100 $**.
5. После проверки документов (обычно от пары дней до недели) появится кнопка **Create new app** — создайте приложение. Вы получите **App ID**, например `3456780`.

**Тип приложения.** DeskForge — это программа, а не игра. Если в настройках приложения (App Admin → Basic Info / «Основные сведения») есть выбор типа, укажите **Software / Application**. Если поле недоступно, напишите в поддержку Steamworks (Support → «Contact Steam Partner Support») с просьбой сменить тип на Software. Так, например, оформлен Wallpaper Engine.

## 2. Настройка приложения в Steamworks

Всё ниже делается в **App Admin** вашего приложения (Steamworks → ваше приложение → «Edit Steamworks Settings»).

> 💡 **Главное правило Steamworks:** любые изменения настроек вступают в силу только после публикации. Вкладка **Publish** → **Prepare for Publishing** → **Publish to Steam** → ввести подтверждение. Если что-то «не работает», первым делом проверьте, опубликованы ли изменения.

### 2.1. Депо (SteamPipe → Depots)
1. Обычно Steam уже создал депо с ID = App ID + 1, например `3456781`. Это **Depot ID**, он понадобится при загрузке.
2. Для депо укажите: **Operating System: Windows**, **Architecture: 64-bit**, Language: All Languages.
3. Нажмите **Save**.

### 2.2. Установка и запуск (Installation → General)
1. **Install Folder:** `DeskForge`.
2. **Launch Options** → **Add new launch option**:
   - Executable: `DeskForge.exe`
   - Launch Type: **Launch (Default)**
   - Operating System: **Windows**, CPU Architecture: **64-bit only**
3. Аргументы запуска оставьте пустыми.

### 2.3. Steam Cloud (нужен для Мастерской)
Мастерская хранит файлы через Steam Cloud, поэтому без квоты публикация работ не заработает.
1. Откройте **Application → Steam Cloud**.
2. **Byte quota per user:** `1073741824` (1 ГБ).
3. **Number of files allowed per user:** `1000`.
4. Сохраните.

### 2.4. Мастерская (Workshop)
1. **Workshop → General**:
   - включите **Enable ISteamUGC for file transfer**;
   - **Workshop visibility**: пока оставьте «Developers only» (Мастерскую видите только вы). Перед релизом переключите на «Everyone».
2. **Теги.** Добавьте теги ровно в таком написании, как в приложении:
   `Anime, Nature, Space, Abstract, Minimal, Cyberpunk, Games, Cars, Fantasy, Pixel Art, Seasonal, Dark, Light, Animated, Static, Widgets`
   (список в коде: `src/shared/workshop/validate.ts`, константа `WORKSHOP_TAGS`).
3. Сохраните.

### 2.5. Опубликуйте настройки
**Publish → Prepare for Publishing → Publish to Steam.**

## 3. Подготовка сборки

### 3.1. Впишите свой App ID
Откройте `package.json` и замените `480` на свой App ID:
```json
"deskforge": {
  "steamAppId": 3456780
},
```
Пока стоит `480`, приложение работает с тестовым приложением Valve («Spacewar»), и публикация в **вашу** Мастерскую невозможна.

Заодно обновите версию: `"version": "0.1.0"`. Steam номер версии не требует, но он виден в описании сборки и в имени архива.

### 3.2. Соберите Windows-версию
Вариант А — на своём компьютере (Windows):
```powershell
cd $HOME\deskforge
git pull
npm install
npm run dist:win
```
Готовая программа окажется в `release\win-unpacked\` (`DeskForge.exe` и файлы рядом).

Вариант Б — готовая сборка с GitHub. Каждый пуш в ветку автоматически собирается на Windows-сервере GitHub. Откройте репозиторий → вкладка **Actions** → «Build Windows» → последний зелёный запуск → внизу раздел **Artifacts** → скачайте `DeskForge-win-x64`. Распакуйте архив **в папку `release\win-unpacked\`** проекта.

> ⚠️ Не забудьте: App ID зашит в сборку. Если вы поменяли `package.json`, соберите заново (или запушьте изменение и скачайте новую сборку из Actions).

### 3.3. Проверьте сборку локально
Запустите `release\win-unpacked\DeskForge.exe` **при запущенном Steam**. Подробный чек-лист — в разделе 6.

## 4. Загрузка сборки в Steam

### 4.1. (Рекомендуется) отдельный аккаунт для загрузки
Хорошая практика — завести отдельный Steam-аккаунт только для сборок. В Steamworks: **Users & Permissions → Manage Users** → пригласите его и дайте права **Edit App Metadata** и **Publish App Changes To Steam** для вашего приложения. Можно загружать и с основного аккаунта.

### 4.2. Загрузка одной командой
В проекте есть скрипт `steam\upload.ps1`. Он сам скачает SteamCMD (официальный консольный клиент Valve), подставит ваши ID и загрузит сборку.

```powershell
cd $HOME\deskforge
.\steam\upload.ps1 -AppId 3456780 -DepotId 3456781 -SteamUser ваш_логин
```

- При первом запуске SteamCMD попросит **пароль** и **код Steam Guard** (из мобильного приложения). Потом он запоминает вход.
- Загрузка ~400 МБ занимает несколько минут. Повторные загрузки быстрее: Steam передаёт только изменившиеся файлы.
- В конце будет `Success` и номер сборки (BuildID).

Если PowerShell ругается «выполнение сценариев отключено», выполните один раз:
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Полезные параметры скрипта:
- `-ContentRoot "D:\путь\к\распакованной\сборке"` — если сборка лежит не в `release\win-unpacked`;
- `-Description "0.1.1 — исправлен экран настроек"` — подпись сборки в Steamworks;
- `-SetLiveBranch beta` — сразу выставить сборку в бета-ветку. Ветку `default` Steam через скрипт выставлять не разрешает, только вручную (следующий шаг).

### 4.3. Сделайте сборку активной
1. Steamworks → **SteamPipe → Builds**.
2. Найдите свою сборку (по BuildID или описанию).
3. В колонке «Set build live on branch» выберите **default** → **Preview Change** → **Set Build Live Now**.

До релиза ветку `default` видите только вы и те, кому вы выдали ключи. Обычные пользователи ничего не увидят.

### 4.4. Установите через Steam
Приложение уже есть в вашей библиотеке Steam: разработчики владеют им автоматически. Если его там нет, создайте ключ: **Steamworks → Request Steam Product Keys → Release Override** (или Beta Testing) и активируйте его в Steam. Затем установите DeskForge из библиотеки, как обычную игру.

## 5. Страница в магазине

**Store Admin** (кнопка «Edit Store Page»). Что заполнить:

| Раздел | Что нужно |
| --- | --- |
| Description | Короткое описание (до 300 символов) и полное, лучше на русском и английском |
| Graphical Assets | Header Capsule **920×430**, Small Capsule **462×174**, Main Capsule **1232×706**, Vertical Capsule **748×896**, Page Background **1438×810** (необязательно) |
| Library Assets | Library Capsule **600×900**, Library Header **920×430**, Library Hero **3840×1240**, Library Logo **1280×720** (PNG с прозрачностью) |
| Screenshots | Минимум **5** скриншотов, 1920×1080. Покажите живые обои, редактор, Мастерскую и экран нагрузки |
| Trailer | Не обязателен, но сильно повышает продажи: 30–90 секунд, как тема собирается за минуту |
| System Requirements | Минимум: Windows 10 64-bit, 4 ГБ ОЗУ, DirectX 11 видеокарта, 1 ГБ места |
| Content Survey | Анкета о контенте (Мастерская = пользовательский контент: отметьте это честно) |
| Pricing | Цена; Valve предложит региональные цены автоматически |
| Tags / Genre | Категория **Utilities / Software**, теги: Utilities, Design & Illustration, Animation & Modeling |

Затем: **Publish → Submit for Review**. Valve проверяет страницу за **3–5 рабочих дней**. После одобрения нажмите **Coming Soon** — появится страница «Скоро выйдет», её нужно держать открытой минимум **2 недели** до релиза.

## 6. Проверка перед релизом (обязательно на настоящей Windows)

Сборка из этого репозитория ещё **ни разу не запускалась на Windows**. Пройдите этот список на Windows 10 **и** Windows 11 перед отправкой на проверку:

- [ ] Приложение запускается из библиотеки Steam, в разделе «Мастерская» горит «Steam: ваше имя».
- [ ] При запуске `DeskForge.exe` напрямую (не из Steam) приложение перезапускается через Steam — так и должно быть с вашим App ID.
- [ ] Живые обои появляются **за значками** рабочего стола, на всех мониторах.
- [ ] Обои ставятся на паузу при запуске игры на весь экран и при работе от батареи (ноутбук).
- [ ] Меняются цвет акцента, тёмный/светлый режим, прозрачность.
- [ ] Windows 11: углы, рамки и цвет заголовков окон.
- [ ] Панель задач: выравнивание, автоскрытие; положение (Windows 10 — все стороны, Windows 11 — сверху/снизу).
- [ ] «Настройки → Вернуть исходный рабочий стол» возвращает всё как было.
- [ ] «Нагрузка» → «Запустить замер» показывает правдоподобные цифры.
- [ ] Мастерская: опубликуйте тестовую тему (пока Мастерская видна только разработчикам), подпишитесь на неё со второго аккаунта — она должна появиться в библиотеке.
- [ ] Автозапуск с Windows работает, приложение стартует свёрнутым в трей.
- [ ] Антивирус (Windows Defender) не ругается.

Найдёте ошибку — пришлите мне текст или скриншот, исправлю, потом пересоберите и загрузите заново (раздел 8).

---

## 7. Релиз

1. Убедитесь, что прошло 30 дней с оплаты и 2 недели с публикации страницы «Скоро выйдет».
2. Отправьте сборку на проверку: **Store Admin / Release → «Mark as ready for review»** (Valve проверяет, что приложение запускается и соответствует странице, это тоже 3–5 рабочих дней).
3. Переключите **Workshop visibility** на **Everyone** и опубликуйте изменения (Publish).
4. Нажмите **Release App** («Выпустить»). Приложение появится в магазине в течение нескольких минут.

---

## 8. Как выпускать обновления

1. Увеличьте версию в `package.json` (например, `0.1.0` → `0.1.1`).
2. Соберите: `npm run dist:win` (или скачайте сборку из GitHub Actions).
3. Загрузите: `.\steam\upload.ps1 -AppId ... -DepotId ... -SteamUser ... -Description "0.1.1 — что изменилось"`.
4. Steamworks → SteamPipe → Builds → выставьте сборку на `default`. У пользователей обновление скачается автоматически.
5. По желанию напишите новость: Steamworks → **Post Event / Announcement**.

**Сначала бета.** Создайте в SteamPipe → Builds ветку `beta` (с паролем или без), загружайте туда (`-SetLiveBranch beta`), проверяйте и только потом переносите на `default`.

## 9. Частые проблемы

| Проблема | Решение |
| --- | --- |
| В приложении «Steam не запущен» | Запустите Steam и войдите. Проверьте, что в `package.json` указан ваш App ID и сборка сделана после этого. |
| Публикация в Мастерскую падает с ошибкой | Проверьте п. 2.3 (квота Steam Cloud) и п. 2.4 (ISteamUGC включён) и что изменения **опубликованы** (Publish). Автору нужно принять соглашение Мастерской — приложение само откроет его страницу. |
| SteamCMD: `Login Failure` / `Rate Limit` | Неверный пароль или слишком много попыток — подождите 30–60 минут. Код Steam Guard вводится сразу после пароля. |
| SteamCMD: `Access Denied` | У аккаунта нет прав на приложение — п. 4.1. |
| `ERROR! Failed to commit build` | Неверный Depot ID или депо не привязано к приложению — проверьте п. 2.1 и опубликуйте изменения. |
| Сборка загружена, но в Steam старая версия | Сборку не выставили на ветку `default` (п. 4.3), или в Steam клиенте выбрана бета-ветка: свойства приложения → Betas. |
| Запуск из Steam: «missing executable» | Проверьте Launch Options (п. 2.2): `DeskForge.exe` лежит в корне сборки, без подпапки. |
| Windows SmartScreen предупреждает | При установке через Steam этого обычно нет. Если нужно убрать полностью — купите сертификат подписи кода (EV/OV) и подписывайте `DeskForge.exe`. |
