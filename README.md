# DeskForge

Программа для кастомизации рабочего стола Windows: живые обои, цвета Windows, стиль окон, положение панели задач, большой редактор для новичков, обмен темами одним файлом и анализ того, сколько ресурсов ПК тема будет потреблять в фоне. Работает сама по себе — без Steam и без аккаунтов.

> Рабочее название — **DeskForge**. Переименовать можно в `package.json` (`productName`), `electron-builder.yml` и `src/renderer/*.html`.

## Установка (для пользователей)

1. Откройте страницу последней сборки: репозиторий → вкладка **Actions** → «Build Windows» → последний зелёный запуск → внизу **Artifacts** → скачайте **DeskForge-Windows** и распакуйте архив. (Если у проекта есть раздел **Releases** — файлы лежат там.)
2. Выберите один из двух файлов:
   - **`DeskForge-Setup-<версия>.exe`** — обычный установщик: двойной щелчок, и через несколько секунд программа установлена, появился ярлык на рабочем столе и в меню «Пуск». Файлы тем `.deskforge` будут открываться двойным щелчком.
   - **`DeskForge-<версия>-portable.exe`** — версия без установки: один файл, просто запустите его (можно носить на флешке).
3. Если Windows покажет «Windows защитила ваш компьютер» (SmartScreen) — нажмите **Подробнее → Выполнить в любом случае**. Это предупреждение появляется у всех программ без платной цифровой подписи.

Удалить программу: «Параметры → Приложения → DeskForge → Удалить». Перед удалением стоит нажать «Настройки → Вернуть исходный рабочий стол».

## Возможности

| Раздел | Что умеет |
| --- | --- |
| **Библиотека** | 14 встроенных шаблонов и свои темы. Живые миниатюры (анимация при наведении), применение в один клик, копия, удаление, бейдж нагрузки. |
| **Редактор** | Палитра инструментов с поиском «Что вы хотите сделать?» (понимает русский и английский, синонимы, «ё», опечатки), популярные инструменты крупными плитками, живой макет рабочего стола (обои + панель задач + окно + значки), слои, инспектор свойств с подсказками «?», режим новичка (редкие настройки спрятаны), отмена/повтор (Ctrl+Z / Ctrl+Y), Ctrl+S, перетаскивание файлов, «Примерить» на 10 секунд на настоящем рабочем столе, живой счётчик нагрузки. |
| **Слои обоев** | Цвет, градиент (с переливом), картинка (параллакс, медленный зум, размытие), видео (со звуком или без), частицы (снег, дождь, светлячки, звёзды, пузыри, сакура; реакция на мышь), шейдеры (северное сияние, волны, плазма, туманность, неоновая сетка), часы, надпись, **звук** (музыка или звуки природы с плавным появлением). Прозрачность и режимы смешивания. |
| **Трей** | Значок рядом с часами: по щелчку — панель с регуляторами громкости, насыщенности и скорости обоев, кнопками «Пауза» и «Стоп» и переключателем автозапуска; по правому щелчку — меню. Звук играет только на основном мониторе и замолкает в играх. |
| **Система** | Настройки Windows в один клик: расширения и скрытые файлы, классическое контекстное меню, секунды в часах, поиск/«Представление задач»/«Виджеты» на панели, «Завершить задачу», веб-результаты в «Пуске», ускорение мыши, игровой режим. Каталог проверенных приложений для оформления (TranslucentTB, Mica For Everyone, Auto Dark Mode, Rainmeter, PowerToys и др.) с установкой и удалением одной кнопкой через winget. Все изменения попадают в резервную копию и откатываются кнопкой «Вернуть исходный рабочий стол». |
| **Оформление Windows** | Цвет акцента (в т. ч. автоматически по обоям), тёмный/светлый режим, прозрачность, акцент на панели задач и в заголовках, анимации окон, углы/рамки/заголовки окон (Windows 11), положение, выравнивание, размер и автоскрытие панели задач, значки рабочего стола. |
| **Производительность** | Мгновенная оценка (CPU, GPU, RAM, VRAM, ватты на ноутбуке, оценка 0–100) с разбивкой по слоям и для разных разрешений; **реальный замер** — тема 8 секунд работает в невидимом окне, а приложение измеряет процессы рендера/GPU, память и плавность кадров; рекомендации с кнопкой «Исправить». |
| **Обмен темами** | Тема сохраняется в один файл `.deskforge` (тема + обложка + картинки/видео) — его можно отправить в мессенджере или выложить в облако; у получателя файл открывается двойным щелчком или перетаскиванием в окно. Импорт работ художника (PNG/JPG/WEBP/GIF/MP4/WEBM) → готовая тема с подобранным акцентом. Проверка перед сохранением, обложка снимается с живого предпросмотра. Файлы тем проверяются при открытии (нельзя подсунуть файлы вне папки темы). |
| **Безопасность** | Перед первым изменением сохраняются исходные настройки Windows; «Вернуть исходный рабочий стол» — в один клик (и опционально при выходе). Только пользовательские настройки (HKCU), без прав администратора и без внедрения в процессы — безопасно рядом с античитами. |
| **Фон** | Приложение живёт в трее, обои ставятся на паузу в играх/полноэкранных приложениях и от батареи, ограничение FPS, автозапуск с Windows (в настройках, в приветствии и в трее), несколько мониторов. Интерфейс на русском и английском, аккуратные монохромные значки вместо эмодзи. Раз в три запуска — предложение поблагодарить автора звездой на GitHub (можно отключить навсегда). |

## Архитектура

```
src/
  shared/                 чистый TypeScript, покрыт тестами
    theme/                формат theme.json (zod-схема), фабрики, встроенные шаблоны
    perf/                 оценщик нагрузки и обработка реального замера
    editor/               история отмен, каталог инструментов и поиск по нему
    sharing/              формат файла .deskforge, импорт работ художника, проверка перед экспортом
    system/               описания системных настроек и каталога приложений
    i18n/                 словари ru / en
    ipc.ts                контракт между окнами и main-процессом
  main/                   Electron main-процесс
    platform/windows.ts   применение темы к Windows (реестр HKCU, SystemParametersInfo, SHAppBarMessage, DWM)
    platform/generic.ts   Linux/macOS: живые обои, системные пункты отключены
    win32/                koffi-привязки Win32, WorkerW (окно за значками), reg.exe
    wallpaperHost.ts      окна обоев на каждом мониторе, пауза в играх/от батареи, параллакс
    perfProbe.ts          реальный замер нагрузки
    storage.ts            библиотека тем на диске, экспорт/импорт .deskforge
    tray.ts               значок в трее, меню и всплывающая панель с регуляторами
    apps.ts               установка приложений через winget
    protocol.ts           deskforge:// — отдача файлов тем с поддержкой Range для видео
  preload/                безопасный мост window.deskforge
  renderer/
    engine/               движок обоев (общий для редактора и рабочего стола): тикер с лимитом FPS, частицы, WebGL-шейдеры
    editor/               редактор
    pages/                библиотека, обмен темами, система, производительность, настройки
    tray/                 всплывающая панель трея
    wallpaper/            страница, которая рисуется за значками рабочего стола
```

Ключевые решения:

- **Один движок рендера** для предпросмотра и рабочего стола — пользователь видит в редакторе ровно то, что получит.
- **Живые обои за значками** — стандартный приём WorkerW (сообщение `0x052C` окну Progman), учтена новая структура окон Windows 11 24H2.
- **koffi** вместо компилируемых нативных модулей: готовые бинарники, сборка не требует Visual Studio.
- **Нет DLL-инъекций.** Поэтому «анимации окон» — это системные анимации Windows (вкл/выкл), а не произвольные эффекты открытия. Произвольные эффекты требуют внедрения в DWM/Explorer (как WindowBlinds), что конфликтует с античитами и антивирусами.
- Формат темы версионирован (`schemaVersion`) и валидируется при каждом чтении — темы из чужих файлов считаются недоверенными.

## Разработка

Требуется Node.js 22+.

```bash
npm install
npm run dev        # Vite + Electron с горячей перезагрузкой
npm test           # unit-тесты (vitest)
npm run typecheck
npm run build      # сборка renderer + main
npm run dist:win   # установщик и portable .exe в release/
```

Интерфейс можно открыть и в обычном браузере (`npx vite`) — тогда вместо main-процесса работает встроенная заглушка API (удобно для вёрстки).

## Сборка .exe

```bash
npm run dist:win   # release/DeskForge-Setup-<версия>.exe и release/DeskForge-<версия>-portable.exe
```

Собирать нужно на Windows (установщик NSIS на Linux требует Wine). Проще всего — через GitHub Actions: каждый пуш в ветку автоматически собирает оба `.exe` на Windows-сервере (`.github/workflows/build-windows.yml`). Если запушить тег вида `v0.1.0`, файлы дополнительно появятся в разделе **Releases** репозитория.

## Ограничения и что дальше

- Windows 11 официально поддерживает панель задач только снизу; «сверху» работает не во всех сборках, «слева/справа» — только в Windows 10. В редакторе недоступные варианты заблокированы с объяснением.
- Смена положения панели и размера значков требует короткого перезапуска Проводника (можно запретить в настройках).
- Стиль рамок/углов окон применяется ко всем обычным окнам (кроме запущенных от администратора) и действует, пока запущен DeskForge.
- Не реализовано пока: свои курсоры, звуко-реактивные обои, пакеты значков, тесты UI (сейчас UI проверяется вручную/скриншотами).
- Константы оценщика нагрузки откалиброваны консервативно; после сбора замеров на реальном железе их стоит уточнить (`src/shared/perf/estimator.ts`).
